## 👋 About Me

I'm a Full-Stack Software Engineer focused on building reliable, scalable, and user-friendly web applications.

I started my professional journey working extensively with **JavaScript, React.js, TypeScript**, and modern frontend technologies, then expanded into backend engineering with **Node.js, Express.js, Laravel, MongoDB, PostgreSQL, and Redis** — building complete, production-ready applications end to end.

Currently, I work at **Taskeasy.io** as a Software Engineer, focusing on Laravel, automation, and Azure DevOps. Previously, I was at **Initux Software Limited**, progressing from Web Developer to Full Stack Engineer.

I enjoy solving complex problems, building practical solutions, and delivering software that creates real value.
